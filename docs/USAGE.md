# 📱 راهنمای استفاده از فیلترشکن شهریار

## مرحله ۱ — نصب

APK را از تب **Actions** ریپو دانلود کن (آرتیفکت `Shahriar-VPN-debug-apk`) و روی گوشی نصب کن. اندروید ۷ به بالا (API 24+) پشتیبانی می‌شود.

هنگام اولین اتصال، سیستم‌عامل یک پنجره می‌گذارد که ازت اجازه **«برقراری اتصال VPN»** می‌خواهد — روی **تأیید/OK** بزن. این یک‌بار برای همیشه است.

## مرحله ۲ — گرفتن کانفیگ

شهریار بدون سرور کار نمی‌کند؛ به یک کانفیگ نیاز داری. معمول‌ترین منابع:

- **ادمین/فروشنده سرور**: معمولاً یک لینک مثل `vless://...` بهت می‌ده
- **باتل‌های تلگرامی**: بعد از ساخت اکانت، لینک کانفیگ می‌فرستند
- **اشتراک (Subscription)**: یک متن base64 که چند ده کانفیگ داخلشه

فرمت‌های پشتیبانی‌شده:

```
vless://uuid@host:port?security=reality&...#نام
vmess://eyJ2IjoiMiIsImFkZCI6Li4u
trojan://password@host:443?sni=...#نام
ss://YWVzLTI1Ni1nY206cGFzc3dvcmQ@host:8388#نام
```

## مرحله ۳ — افزودن کانفیگ

1. برنامه را باز کن → تب **کانفیگ‌ها**
2. دکمه **+** را بزن
3. لینک را paste کن (یا کل محتوای اشتراک را)
4. **افزودن** را بزن — تعداد کانفیگ‌های واردشده نمایش داده می‌شود

> کانفیگی که تیک سبز روش است، کانفیگ «فعال» شماست. برای تغییر، روی کانفیگ دیگری بزن.

## مرحله ۴ — اتصال

1. تب **اتصال** را باز کن
2. دکمه پاور نئونی بزرگ را بزن ⚡
3. رنگ دکمه:
   - 🔴 **قطع** → آماده اتصال
   - 🟡 **در حال اتصال...** → هسته روشن می‌شود
   - 🟢 **وصل** → تونل برقرار شد!

## مرحله ۵ — یوتیوب 🎬

دکمه **یوتیوب** پایین صفحه را بزن — مستقیم بازش می‌کند. حالا ویدیوها را تماشا کن.

## ابزارهای کمکی

- **تست پینگ**: وقتی وصل هستی، پینگ واقعی از داخل تونل را نشان می‌دهد (بخش لاگ)
- **ترمینال لاگ**: تب «لاگ» همه رویدادهای هسته را به سبک ترمینال نشان می‌دهد — عیب‌یابی اینجاست
- **آمار آپلود/دانلود**: کارت پایین صفحه اتصال، لحظه‌ای آپدیت می‌شود

## عیب‌یابی 🔧

| مشکل | راه‌حل |
|---|---|
| «هیچ کانفیگی انتخاب نشده» | برو تب کانفیگ‌ها، یکی را انتخاب کن (بزن روش تا سبز شود) |
| «دسترسی VPN داده نشده» | دکمه پاور را دوباره بزن و این بار OK کن |
| وصل است ولی هیچ سایتی باز نمی‌شود | کانفیگ منقضی/غلط است — از ادمین کانفیگ تازه بگیر |
| پینگ ناموفق | سرور فیلتر شده یا ترافیکش تمام شده — سرور دیگر را امتحان کن |
| یوتیوب وصل نیست ولی بقیه اوکیه | اپ یوتیوب را کامل ببند (swipe away) و دوباره باز کن |
| برنامه بعد از آپدیت سیستم کار نمی‌کند | در تنظیمات اندروید → VPN → اتصال شهریار را «فراموش» کن و دوباره وصل شو |

## نکات حرفه‌ای 💡

- **QUIC**: به‌صورت پیش‌فرض UDP:443 بلاک می‌شود تا اپ‌ها به TCP برگردند — پایداری بهتری در برابر اختلال می‌دهد
- **حالت پرواز**: اگر اتصال به‌هم ریخت، حالت پرواز را ۵ ثانیه روشن/خاموش کن و دوباره وصل شو
- **باتری**: سرویس با نوتیفیکیشن دائمی اجراست؛ برای قطع کامل از دکمه «قطع اتصال» داخل نوتیفیکیشن هم می‌توانی استفاده کنی
